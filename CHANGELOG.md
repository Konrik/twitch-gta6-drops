# Что нового

Скрипт показывает разделы отсюда в окне «⬆ Обновления». Формат заголовка: `## X.Y — ДД.ММ.ГГГГ`,
под ним строки, которые начинаются с «-». Английская версия — [CHANGELOG.en.md](CHANGELOG.en.md):
при каждой новой версии заполняй оба файла.

## 3.0 — 22.11.2026
- Мгновенные обновления: Tampermonkey теперь ставит маленький загрузчик, а сам скрипт загружается с GitHub при каждом открытии Twitch. Новая версия работает сразу после обновления страницы (с задержкой GitHub примерно до минуты).
- Если GitHub не отвечает, работает сохранённая копия скрипта.
- Открытые вкладки раз в 15 минут проверяют новую версию; вкладки с автопросмотром и наградами перезапускаются на неё сами.
- ❤ Фолловы: Twitch отвечал «service error» на запрос фолловов. Теперь скрипт пробует несколько вариантов запроса, запоминает рабочий и пишет в журнал, какой подошёл. Если не работает ни один — пишет об этом один раз и повторяет через 30 минут, а не каждые 2.
- Журнал: у каждой загрузки страницы есть причина (плановое обновление инвентаря, переход на канал, перезапуск на новую версию) или пометка «обновлена не скриптом».
- Настройка «Непрозрачность плашки без наведения мыши» — от 50 до 100 %.

## 2.6 — 22.11.2026
- Компактная плашка: кнопки — значки без слов (подсказка при наведении), одна строка.
- Плашка полупрозрачная и плавно проявляется, когда наводишь мышь.
- Кнопка «–» сворачивает плашку до значка состояния: 👀✔ смотрю, 👀⏳ жду, 👀🔎 ищу, 🎁 N — награды.
- Плашку можно перетащить мышкой куда угодно; место запоминается. Окна открываются рядом с ней.

## 2.5 — 22.11.2026
- Английский язык: кнопка EN / RU на плашке переключает весь интерфейс и журнал (или ⚙ → «Язык»).
- По умолчанию язык выбирается как у Twitch: русский Twitch — русский скрипт, иначе английский.
- Смена языка сразу применяется во всех открытых вкладках Twitch.
- README и список изменений теперь есть и на английском.

## 2.4 — 22.11.2026
- Автообновление: скрипт теперь лежит на GitHub, Tampermonkey сам подтягивает новые версии.
- Кнопка с версией на плашке открывает окно «⬆ Обновления»: проверить сейчас, что нового, установить.
- Раз в 6 часов скрипт сам проверяет GitHub и подсвечивает «⬆», если вышла новая версия.
- После обновления вкладки с автопросмотром сами перезапускаются на новую версию (можно выключить в ⚙).

## 2.3
- Журнал событий 📜 с копированием и очисткой.
- Сторож переходов: зависший переход или запрос к Twitch больше не останавливает скрипт.
- Проверка стрима через API Twitch: скрипт не залипает на закончившемся стриме.
