# Twitch GTA VI Drops — автопросмотр

Tampermonkey-скрипт для Twitch. Держит вкладку на живом стриме GTA VI с дропсами и сам
переключает канал, если стрим закончился или стример сменил игру. Во второй вкладке может
сам собирать награды в инвентаре. Интерфейс на русском и английском.

Кампания дропсов GTA VI на Twitch идёт с 19 по 30 ноября 2026, коды надо забрать до 7 декабря.

## Установка

1. Поставь расширение **Tampermonkey**:
   [Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) ·
   [Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) ·
   [Firefox](https://addons.mozilla.org/firefox/addon/tampermonkey/).
2. **Только Chrome и Edge:** открой `chrome://extensions` (в Edge — `edge://extensions`),
   у Tampermonkey нажми «Сведения» и включи **«Разрешить пользовательские скрипты»**.
   В старых версиях Chrome такого переключателя нет — тогда включи «Режим разработчика»
   справа вверху на той же странице. Без этого скрипты не запускаются.
3. Открой ссылку:
   **[установить скрипт](https://raw.githubusercontent.com/Konrik/twitch-gta6-drops/main/twitch-gta6-drops.user.js)**
4. Tampermonkey покажет страницу скрипта — нажми **«Установить»**.
5. Открой или обнови [twitch.tv](https://www.twitch.tv). Слева внизу появится кнопка **«🎮 GTA6»**.

Если у тебя уже стоит старая версия, скопированная вручную, просто открой ссылку из шага 3 —
Tampermonkey предложит её обновить, настройки сохранятся. После этого обновления будут приходить сами.

## Как пользоваться

Нажми «🎮 GTA6» и выбери:

- **👀 Смотреть в этой вкладке** — вкладка сама находит живой стрим GTA VI с дропсами и держит его.
  Сначала смотрит ⭐ приоритетные каналы из настроек, потом ❤ твои фолловы, потом всю категорию.
- **🎁 Награды в новой вкладке** — открывает инвентарь в новой вкладке и сам жмёт «Получить».

Обе вкладки должны оставаться открытыми (можно в фоне). Нужно войти в свой аккаунт Twitch.

Кнопки на плашке:

| Кнопка | Что делает |
|---|---|
| ⚙ | Настройки: через сколько переключать стрим, приоритетные каналы, 160p, язык и т. д. |
| 📜 | Журнал событий. Если что-то пошло не так, нажми «Копировать» и пришли текст в [Issues](https://github.com/Konrik/twitch-gta6-drops/issues). |
| ⏹ Стоп | Выключить скрипт в этой вкладке. |
| EN / RU | Переключить язык. Сразу меняется во всех открытых вкладках Twitch. |
| vX.Y | Версия. Нажми, чтобы проверить обновления и посмотреть, что нового. |

В названии вкладки видно состояние: 🟢 Фарм, 🟡 Жду, 🔎 Ищу, 🎁 Награды (N).

## Язык

По умолчанию скрипт говорит на языке твоего Twitch: русский интерфейс Twitch — русский
скрипт, любой другой — английский. Переключить вручную: кнопка **EN / RU** на плашке или
⚙ → «🌐 Язык / Language» (там же можно вернуть «Авто»). Журнал пишется на том языке,
который был включён в момент записи.

## Обновления

- Tampermonkey сам проверяет новую версию на GitHub (по умолчанию раз в сутки) и ставит её.
- Скрипт и сам проверяет GitHub раз в 6 часов. Если вышла новая версия, на плашке появится
  жёлтая кнопка **«⬆ vX.Y»**. Нажми её, потом «⬆ Установить» и «Обновить» в Tampermonkey.
- Уже открытые вкладки с автопросмотром перезапускаются на новую версию сами (выключается в ⚙).
- Проверить обновление вручную: нажми на версию на плашке → «🔍 Проверить сейчас».
  Или в Tampermonkey: Панель управления → выбери скрипт → «Проверить обновления».

Список изменений — в [CHANGELOG.md](CHANGELOG.md).

## Для разработки

Весь скрипт — один файл [`twitch-gta6-drops.user.js`](twitch-gta6-drops.user.js), без сборки.
Все тексты интерфейса и журнала — в словаре `STR` (разделы `ru` и `en`). Добавляешь текст —
добавь его в оба раздела.

Tampermonkey обновляет скрипт, только если **`@version` стала больше**. Поэтому при каждом изменении:

```sh
node tools/bump.mjs 2.6      # поднимет версию в двух местах кода, добавит раздел в оба CHANGELOG
# допиши в CHANGELOG.md и CHANGELOG.en.md, что изменилось
node tools/check.mjs         # проверка: синтаксис, версии, оба CHANGELOG, ссылки обновления, словарь
git commit -am "2.6: ..." && git push
```

Тот же `check.mjs` запускается на GitHub при каждом push. Ещё он падает, если файл скрипта
изменили, а версию не подняли.

Raw-ссылка без хеша коммита всегда отдаёт последнюю версию из ветки `main`. GitHub кэширует её
до 5 минут, так что новая версия становится видна не сразу.
